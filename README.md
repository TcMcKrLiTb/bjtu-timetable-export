# 课表导出 (classtables)

一个油猴（Tampermonkey / Violentmonkey）脚本，从 **一体化智慧教学平台**（`123.121.147.7:88/ve`）
的"我的课表"页面导出整学期课表，支持 **ICS 日历 / CSV / JSON** 三种格式。

## 安装

1. 浏览器安装 Tampermonkey（或 Violentmonkey）。
2. 新建脚本，把 `classtables.user.js` 的内容整个粘贴进去，保存。
3. 登录平台，打开"我的课表"页面
   （`.../ve/back/rp/common/myTimeTableDetail.shtml?method=skipIndex&sessionId=...`）。
4. 右下角会出现 **课表导出** 面板。

## 使用

1. 点 **抓取全学期** —— 脚本会按页面上 `#jxzId` 的周次列表，逐周抓取课表并合并。
   进度条走完后显示"共 N 周、M 次课、归并为 K 条"。
2. 点 **导出 ICS / CSV / JSON** 任意一个即可下载。

## 关键设计：周次按节假日重排

平台里的周次**不是**简单的"第一周 + (N-1)×7 天"。学校会按节假日重排，例如：

| 周次 | 起止 |
|---|---|
| 第 3 周 | 2026-09-21 至 2026-09-27 |
| 第 4 周 | **2026-10-05** 至 2026-10-11 |  ← 跳过国庆假期

所以脚本**不推算日期**，而是直接读页面 `#jxzId` 下拉框里每个周的真实起止日期，
再用「该周周一 + (星期几 − 1)」定位每次课的实际日期。
这样导出的 ICS 在假期前后不会错位。

## 其它实现要点

- **页面每次只渲染一周**。每个节次是一个独立的 `<ul class="timetable-tabletlist">`，
  里面 `li.table-list` 是时间标签、`li.table-list2` 是 7 个格子；
  只渲染**有课**的行，所以节次号由行首时间落到哪个标准节次来判定（不是行下标）。
  上午存在 `10:10` 和 `10:30` 两种作息，脚本按标准节次表映射到第 2 节。
- **页面是 GBK 编码**，抓取后用 `TextDecoder('gbk')` 解码，否则中文乱码。
- **归组**：按「课程名 + 星期 + 节次 + 教室」合并同一门课的多次出现，周次压缩成
  `第01-03,05-16周`。
- **导出加 BOM**，这样 Excel / Outlook 能正确识别 UTF-8 中文。
- ICS 每个课次一条 `VEVENT`，`DTSTART/DTEND` 用真实日期时间，`TRANSP:TRANSPARENT`；
  时段为每节 110 分钟，最后一节晚课 50 分钟。

## 输出格式

三种格式的字段约定：

- `课程表.json` — `weekNum`(星期 1-7)、`courseNum`(节次)、`name`、`location`、
  `initInfo`(周次)、`date`(周次数组)、`teacher`、`allInfo`
- `课程表.csv` — 表头 `课程|星期,星期一..星期日`，行是 `第N节 [起 - 止]`
- `课表.ics` — 标准 iCalendar

> 注意：页面上的教室只有房间号（如 `SY208`），没有校区/教学楼全称，
> 所以导出的 `location` 只有房间号。
